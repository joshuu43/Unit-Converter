# Unit Converter

A simple, lightweight unit conversion website built with **HTML, CSS-free native browser styling, and JavaScript**. Convert measurements directly in your browser without installing anything.

### 🌐 Live Demo

**[Open Unit Converter](https://joshuu43.github.io/Unit-Converter/)**

## Project Challenge

This project was developed based on the [Unit Converter challenge on roadmap.sh](https://roadmap.sh/projects/unit-converter). The challenge focuses on building a web application that converts values between different measurement units.

## Features

- **Length converter** — access the length conversion page.
- **Weight converter** — convert between milligrams, grams, kilograms, ounces, and pounds.
- **Temperature converter** — convert between Celsius, Fahrenheit, and Kelvin.
- **Instant results** displayed on the page after submitting a conversion.
- **No backend required** — runs entirely in the browser.

## Technologies

- HTML5
- JavaScript (Vanilla JS)
- GitHub Pages for hosting

## Getting Started

1. Visit the [live website](https://joshuu43.github.io/Unit-Converter/), or clone the repository:

   ```bash
   git clone https://github.com/joshuu43/Unit-Converter.git
   ```

2. Open `index.html` in your browser.
3. Select a converter, enter a value, choose the source and destination units, and click **Convert**.
